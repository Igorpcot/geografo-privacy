Política de Privacidade — Geógrafo

Vigência: 7 de outubro de 2025

Responsável: Master Kmz

Contato: igorpcot@gmail.com

1. Visão Geral

O Geógrafo é um assistente de análise geoespacial desenvolvido por Master Kmz para interpretar documentos, extrair referências geográficas e gerar produtos cartográficos como tabelas, arquivos KML e mapas. Esta política descreve como os dados são tratados quando o agente é utilizado por meio da plataforma da OpenAI.

2. Coleta de Dados

Durante o uso do Geógrafo podem ser coletados:

  • Entradas do usuário: textos e arquivos enviados durante as interações.
  • Dados geográficos: nomes de locais, coordenadas e atributos espaciais derivados das suas entradas.
  • Dados de APIs: informações consultadas em serviços de terceiros, como APIs meteorológicas.
  • Metadados de uso: dados não identificáveis tratados automaticamente pela OpenAI (timestamps, IDs de sessão etc.).

3. Uso dos Dados

Os dados são utilizados para:

  • Gerar análises geográficas e produtos KML solicitados.
  • Buscar informações complementares em APIs confiáveis.
  • Melhorar a experiência do usuário e a precisão do modelo.

Master Kmz não vende nem compartilha dados com terceiros para fins de publicidade.

4. Armazenamento e Retenção

Entradas de usuários e saídas geradas podem ser armazenadas temporariamente para processamento e melhoria do serviço. Os dados são mantidos apenas pelo tempo necessário ou conforme exigido pela plataforma da OpenAI. Você pode solicitar a exclusão antecipada entrando em contato pelo e-mail indicado.

5. Compartilhamento de Dados

  • OpenAI: todas as interações são processadas pela API da OpenAI e estão sujeitas à política de privacidade da OpenAI.
  • APIs externas: quando necessário, o Geógrafo consulta APIs de terceiros estritamente para fornecer as informações solicitadas, compartilhando apenas os dados mínimos necessários.

6. Segurança

Medidas técnicas e organizacionais razoáveis são adotadas para evitar acesso, alteração ou divulgação não autorizados. Ainda assim, recomenda-se não enviar dados pessoais sensíveis por meio do agente.

7. Direitos dos Usuários

  • Solicitar acesso, correção ou exclusão dos seus dados.
  • Revogar o consentimento para o tratamento de dados.
  • Entrar em contato com o responsável para assuntos relacionados à privacidade.

8. Atualizações desta Política

Esta política pode ser atualizada periodicamente. Alterações relevantes serão comunicadas nesta mesma página com uma nova data de vigência.

Ao utilizar o Geógrafo, você concorda com esta Política de Privacidade.
